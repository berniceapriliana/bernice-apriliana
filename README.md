# Profil Saya - Tugas Pertemuan 5

Website profil responsif sederhana (HTML, CSS, JavaScript tanpa framework).

Fitur:
- Layout responsif dengan viewport meta tag dan lebar container berbasis persen
- Kartu hobi: 1 kolom (< 768px) dan 3 kolom (>= 768px) memakai media query
- Tombol Ubah Teks (querySelector, textContent, addEventListener)
- Tombol Ganti Tema (classList.toggle)

Cara membuka: buka file `index.html` di browser.
